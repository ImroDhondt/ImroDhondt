## About me

I'm **Imro Dhondt**, a third-year Bachelor of Applied Computer Science student specialising in Software Engineering at Howest.

I have been fascinated by computers and applications from a young age. I enjoy understanding how software works, solving problems, designing systems, learning new technologies, and turning ideas into meaningful applications.

My main focus is **web and Android development**, but my projects have also introduced me to software architecture, distributed systems, event-driven communication, databases, automated testing, Docker, Terraform, and cloud deployment.

I'm curious, patient, and motivated. I enjoy working independently on larger projects, collaborating with a team, and improving software through feedback and iteration.

## Featured projects

### QHSE Management Platform

A self-hostable full-stack platform for Quality, Health, Safety, and Environment workflows.

- **Status:** Active development.
- **Role:** Solo developer.
- **Stack:** TypeScript, NestJS, Next.js, React, PostgreSQL, Prisma, Docker.
- **Highlights:** Declarative workflow state machines, CAPA tracking, risk matrices, audit logging, role-aware workflows, secure authentication, and bilingual support.

### Howestprime

A distributed cinema booking and ticketing platform built around microservices and asynchronous communication.

- **Status:** Completed course project.
- **Role:** Solo developer.
- **Stack:** .NET, Deno, TypeScript, RabbitMQ/LavinMQ, PostgreSQL, MongoDB, Docker, Terraform, Azure.
- **Highlights:** Event-driven communication, domain modelling, independent databases, cloud infrastructure, and GitHub Actions quality gates.

### Freeze or Sneeze

A native Android educational game where players diagnose illnesses, treat patients, and prevent disease outbreaks.

- **Status:** Public playtest.
- **Role:** Solo developer.
- **Stack:** Kotlin, Jetpack Compose, Clean Architecture, MVVM, Room, DataStore, Hilt.
- **Highlights:** Real-time contagion simulation, custom Canvas rendering, progression systems, accessibility options, and 457 passing unit tests.

### Adria

A team-built smart hotel guest portal for contactless room services and IoT room controls.

- **Status:** Team prototype.
- **Role:** Primary frontend contributor.
- **Stack:** Vue, .NET, MySQL, ESP32, Web Push, Docker.
- **Highlights:** Activity planning, food ordering, room controls, API integration, date/time synchronisation, and responsive interface development.

### Roblox incremental game

An early-stage game project built while learning Lua and exploring progression mechanics.

- **Status:** Early development.
- **Role:** Solo developer.
- **Stack:** Roblox and Lua/Luau.
- **Highlights:** Independent learning, game mechanics, progression systems, and iterative experimentation.
